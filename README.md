# bAIble v2

The living public governance layer for disciplined human–AI work.

## Core loop

`INTENT → CONTEXT → GROUNDING → RULES → PLAN → ACTION → EVIDENCE → VERIFICATION → ACCEPTANCE → LEARN → PERSIST`

FOUND ≠ UNDERSTOOD ≠ VERIFIED ≠ CANONICAL

IMPLEMENTED ≠ VERIFIED ≠ ACCEPTED

CONTEXT CONTINUITY ≠ MEANING CONTINUITY

## One ecosystem, three systems

bAIble, FederAItion and UnAiversed are treated as one human–AI ecosystem with different responsibilities:

- **bAIble** — governance, language, rules, roles, lessons, verification discipline and reusable workflows.
- **FederAItion** — runtime, orchestration, durable evidence, decisions and implementation state.
- **UnAiversed** — contextual and relational map: what connects to what, under which scope, provenance, meaning and time.

Human Intelligence (HI) and Artificial Intelligence (AI) are participating entities that create, use, inspect and evolve this ecosystem.

## System map

- Human — intent, material decisions, acceptance and intervention gates.
- rAIda — THINK / COORDINATE / REMEMBER-TO-CHECK.
- Agent — PREPARE / REASON / EXECUTE / RECORD.
- Evidence — observable execution.
- Verification — evidence-backed checking.
- Reality Check (RC) — compare human and AI working maps; detect meaning/context divergence.
- Fact Check (FC) — verify claims, facts, assumptions and evidence.
- Watchdog — CONTINUE / MONITOR / ESCALATE.
- WheeAIls — relevant support/reminders, not authority.
- Wolf — ORIENT / TEACH / ONBOARD; never decides or verifies.

## Living governance

bAIble changes through evidence and experience:

`EXPERIENCE → CANDIDATE → GENERALIZE → VALIDATE → INTEGRATE → REVIEW AGAIN`

Repeated failure is a signal to inspect the process, not a reason to endlessly patch the same incident or automatically create a new rule.

Preserve provenance when meanings evolve. A surviving name, record or relationship does not prove that the original meaning survived or that a claim is true.

Reality outranks documentation. This repository is the official living v2 path; earlier laboratories remain source material and history.
