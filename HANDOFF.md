# bAIble v2 — Handoff

A handoff must preserve enough information for the next worker to continue without guesswork.

Minimum: task id, intent, current state, role, scope, dependencies, authorized sources, verified sources, rules, expected output, expected evidence, completed work, actual evidence, unresolved questions, conflicts, next authorized transition and recovery/rollback notes where relevant.

A handoff is a durable contract, not a conversational “good luck”.
