# Start Here

bAIble is a living public guide for humans and AI working together deliberately.

The shortest route:
UNDERSTAND → CLASSIFY → PLAN → ACT → VERIFY → REALITY CHECK → LEARN → PERSIST

Start with BIBLE, LANGUAGE, ARCHITECTURE, ONBOARDING, VERIFICATION, REALITY_CHECK, CONTEXT_AND_MEMORY, HANDOFF and PUBLIC_PRIVATE_BOUNDARY.

The public bAIble is not project memory. Project context, evidence, implementation and secrets belong in appropriate private systems.

rAIda coordinates. UnAiversed maps relationships. Watchdog monitors observable workflows. Reality Check verifies alignment and evidence. Wolf teaches orientation.

Start small. Learn as you go. Build only what solves a real problem.
