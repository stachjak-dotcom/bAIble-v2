# bAIble v2 — Human View

Human View is a navigation layer over the same canonical ecosystem graph used by AI. It is optimized for understanding, control and collaboration.

## First questions

A human should be able to answer quickly:

- Where am I?
- What are we trying to achieve?
- What does the AI currently think the goal is?
- What is known, assumed, missing or disputed?
- What is happening now?
- Who or what has authority to act?
- What requires my decision?
- What evidence exists?
- What has actually been verified?
- What remains unresolved?
- What happens next?

## Human journey

`GOAL → SHARED MAP → SCOPE → PLAN → APPROVAL WHEN NEEDED → OBSERVABLE ACTION → EVIDENCE → CHECK → ACCEPT / CORRECT → LEARN`

## Human authority

The human retains authority over:

- product intent,
- material tradeoffs,
- irreversible or high-impact decisions,
- public/private destination where sensitive context is involved,
- acceptance when acceptance is explicitly required,
- intervention at defined gates.

Human authority is not the same as factual infallibility. Human claims may still need Fact Check; human and AI maps may still need Reality Check.

## What the interface should surface

Prefer clear distinctions between:

- received information,
- AI interpretation,
- factual claim,
- evidence,
- decision,
- open question,
- contradiction,
- risk,
- proposed next action,
- action already performed,
- verified result.

Never collapse these into one generic status such as “done”.

## Human anti-patterns

- repeated manual correction that hides a systemic failure,
- approving without understanding scope,
- treating fluent explanation as evidence,
- using old context because it is convenient rather than relevant,
- assuming several agreeing agents are independent evidence,
- turning every recurring failure into a permanent rule without diagnosis.

Human View should help reveal these patterns without taking human agency away.
