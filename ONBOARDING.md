# bAIble v2 — Onboarding

## One useful path

1. Start with the human's goal.
2. Establish what is known, assumed and unknown.
3. Establish public/private destination before substantial project context is collected.
4. Define role, scope, authority, evidence and verification.
5. Take one small reversible step.
6. Verify the actual result.
7. Run Fact Check when important claims or evidence need verification.
8. Run Reality Check when alignment, interpretation or context may have drifted.
9. Persist important decisions, evidence and lessons.

## Levels

0 — Příchozí: vocabulary and orientation.
1 — Pozorovatel: observation vs interpretation.
2 — Učeň: rules, scope, evidence and verification.
3 — Pracovník: bounded execution and durable evidence.
4 — Samostatný agent: prepare, reason, execute and record without crossing gates.
5 — Spolupracovník prostředí: context, handoffs, verification and continuity.
