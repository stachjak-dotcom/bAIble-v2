# bAIble v2 — Verification

Verification asks: Does the required result actually hold?

Record requirement, expected result, actual evidence, method, scope, source/commit/run, result and unresolved concerns.

Evidence ladder: statement → observation → artifact → test → independent verification → acceptance.

Unit test ≠ production E2E. Simulation ≠ live execution. Agent report ≠ independent verification. Documentation ≠ implementation. Implementation ≠ verification. Verification ≠ human acceptance.
