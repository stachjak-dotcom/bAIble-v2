# bAIble v2 — Fact Check

## Purpose

**Fact Check (FC) is the verification mechanism for claims, facts, assumptions and evidence.**

It asks:

> **“Is what we are treating as true actually supported by appropriate evidence?”**

Fact Check is distinct from Reality Check.

- **Reality Check (RC)** compares the human's and AI's current working maps to expose divergence in understanding.
- **Fact Check (FC)** tests factual or evidential claims against sources, artifacts, observations, tests or other appropriate evidence.

A Reality Check may discover that a Fact Check is needed. A Fact Check does not replace map alignment.

## What FC compares

When relevant, compare:

- claim,
- source and provenance,
- verified facts / observations,
- evidence,
- assumptions,
- hypotheses,
- conflicts,
- missing evidence,
- scope and time validity,
- next required check.

A compact form is:

`CLAIM → SOURCE / EVIDENCE → CHECK → SUPPORTED / CONTRADICTED / UNCERTAIN / MISSING EVIDENCE → NEXT CHECK`

## Epistemic discipline

FOUND ≠ UNDERSTOOD ≠ VERIFIED ≠ CANONICAL.

A statement is not evidence merely because an agent wrote it.
A document is not implementation.
Implementation is not verification.
A passing local test is not automatically production evidence.
Agreement between agents sharing the same source is not independent evidence.

If the actual problem is “we did not check”, record the missing check instead of hiding it behind vague uncertainty.

## Possible outcomes

- **SUPPORTED** — evidence appropriate to the claim supports it within the stated scope.
- **CONTRADICTED** — relevant evidence conflicts with the claim.
- **UNCERTAIN** — evidence exists but does not resolve the claim.
- **MISSING_EVIDENCE** — the required check or evidence has not been obtained.
- **OUT_OF_SCOPE** — the available evidence does not cover the claim being made.
- **STALE** — evidence may no longer represent the relevant time/version.

These labels describe the check result; they do not automatically make a claim canonical.

## Boundary

Fact Check does not decide human intent and does not infer alignment between human and AI.

If the question is:

> “Are we talking about the same thing?”

use **Reality Check**.

If the question is:

> “Is this claim actually supported?”

use **Fact Check**.

## Origin of the split

Fact Check preserves the useful factual/evidential verification behavior that had accumulated under the name Reality Check while Reality Check itself is restored to its original map-alignment purpose.

This split exists specifically to prevent a useful extension from silently replacing the meaning of the original mechanism.
