# bAIble v2 — Provenance

Every important claim should retain its origin and status.

Source classes: PUBLIC-SOURCE, PROJECT-SOURCE, EXPERIMENT, GENERALIZED-LESSON, PRIVATE.

Never cite a private source as public. Never imply access to a source the current worker cannot access.

Minimal record: Claim, Status, Source class, Source, Evidence, Limitations, Last verified.

Provenance is part of the verification boundary.
