# bAIble v2 — Architecture

Human → Governance → Coordination → Context → Agent → Evidence → Verification → Continuity

Human owns intent, material decisions and intervention gates.
bAIble defines reusable governance.
rAIda coordinates task state, context checks, role/scope, handoffs and authorized transitions.
UnAiversed maps relationships; it is not automatically truth.
WheeAIls surfaces relevant reminders; reminders are not authority.
Agent performs bounded preparation, reasoning, execution and recording.
Evidence records observable execution.
Verification checks whether the required result actually holds.
Watchdog maintains continuity only through authorized transitions.
Wolf orients and teaches; it has no decision or verification authority.

## Canonical path
INTENT → CONTEXT → GROUNDING → POLICY → PLAN → APPROVAL → ACTION → EVIDENCE → VERIFY → ACCEPT → LEARN

Failure states remain first-class: MISSING_CONTEXT, CONFLICT, OUT_OF_SCOPE, WAITING_HUMAN, VERIFY_FAILED, FAILED, CANCELLED.

No layer may silently acquire another layer's authority.
