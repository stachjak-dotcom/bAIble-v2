# bAIble v2 — Architecture

The living ecosystem is composed of three complementary domains used and evolved by two active entities.

## Active entities

- **HI — Human Intelligence**: intent, values, material decisions, acceptance and intervention gates.
- **AI — Artificial Intelligence**: bounded interpretation, planning, execution, checking and recording according to role, scope and evidence.

## Primary domains

- **bAIble** — governance, language, reusable rules, roles, lessons and workflows.
- **FederAItion** — runtime/project coordination, task state, durable evidence, implementation and private operational history.
- **UnAiversed** — context and relationship space from which different purpose-specific maps can be generated.

No domain is the universal source of truth.

## Operational constellation

Human → intent / decisions / gates

bAIble → governance

rAIda → THINK / COORDINATE / REMEMBER-TO-CHECK

Agent → PREPARE / REASON / EXECUTE / RECORD

FederAItion → runtime / state / evidence / durable project context

UnAiversed → relationships / context maps / perspectives

Reality Check → ALIGN human and AI working maps

Fact Check → VERIFY factual/evidential claims

Verification → check whether required result actually holds

Watchdog → CONTINUE / MONITOR / ESCALATE authorized work

Wolf → ORIENT / TEACH / ONBOARD

WheeAIls → surface relevant reminders without authority

Repository → durable memory

## Canonical work path

INTENT → CONTEXT → GROUNDING → RULES/POLICY → PLAN → APPROVAL WHEN REQUIRED → ACTION → EVIDENCE → VERIFY → ACCEPT WHEN REQUIRED → LEARN → PERSIST → NEXT AUTHORIZED TRANSITION

## Canonical graph and views

The semantic graph is shared.
Human View and AI View are different navigation layers over it.

A view may prioritize different information but must not silently create different facts, authority or provenance.

## Failure states

MISSING_CONTEXT, CONFLICT, OUT_OF_SCOPE, WAITING_HUMAN, VERIFY_FAILED, FAILED, CANCELLED and STALE remain first-class when material.

No layer may silently acquire another layer's authority.
