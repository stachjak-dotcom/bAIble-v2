# bAIble v2 — Architecture

## Ecosystem

`HI ↔ { bAIble ↔ FederAItion ↔ UnAiversed } ↔ AI`

This is one ecosystem, not a hierarchy.

- **bAIble** governs reusable collaboration patterns.
- **FederAItion** carries runtime, orchestration, durable evidence and operational state.
- **UnAiversed** maps contextual relationships and perspectives.
- **Human** owns intent, material decisions and acceptance gates.
- **AI / Agent** performs bounded preparation, reasoning, execution and recording.

## Coordination systems

- rAIda — task state, context/preflight, role/scope, handoffs and authorized transitions.
- Reality Check — human/AI map alignment.
- Fact Check — factual/evidential checking.
- Verification — required-result checking.
- Watchdog — observable continuity, continuation and escalation.
- WheeAIls — relevance/support reminders.
- Wolf — onboarding/orientation.

## Canonical path

`INTENT → CONTEXT → GROUNDING → POLICY → PLAN → APPROVAL → ACTION → EVIDENCE → VERIFY → ACCEPT → LEARN → PERSIST`

## Authority boundary

No layer may silently acquire another layer's authority.

A relation does not transfer authority, truth, scope or visibility merely by association.

## Failure states

MISSING_CONTEXT, CONFLICT, OUT_OF_SCOPE, WAITING_HUMAN, VERIFY_FAILED, FAILED, CANCELLED and STALE should remain inspectable.
