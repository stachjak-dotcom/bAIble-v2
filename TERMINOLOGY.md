# bAIble v2 — Terminology

| Term | Meaning | Status |
|---|---|---|
| bAIble | Governance, rules, guardrails, evidence, verification and learning | Established |
| rAIda | Coordination/orchestration layer | Implemented in FederAItion; public contract generalized here |
| UnAiversed | Contextual/relational mapping space | Concept + private implementation context |
| WheeAIls | Beginner guidance / small wheels | Established concept |
| Wolf | Orientation/onboarding persona | Established concept |
| Reality Check (RC) | Alignment mechanism: compare human and AI working maps and expose divergence in meaning/context | Restored original meaning |
| Fact Check (FC) | Verification mechanism for claims, facts, assumptions and evidence | Established split from former RC verification use |
| Watchdog | Continuity/monitoring layer | Implemented in FederAItion; public contract generalized here |
| Handoff | Structured transfer of work context and evidence | Established workflow |
| Provenance | Origin and status of claims | Established practice |
| Gray data | Unresolved input not automatically treated as fact, requirement or conclusion | Evolving concept |
| Context Item | Addressable context with provenance, scope, status and relations | Established v2 contract |
| Context drift | Shift in current interpretation caused by lost, partial or reweighted context | Failure mode |
| Meaning drift | A term survives while its original purpose or meaning is silently replaced | Failure mode |
| Semantic continuity | Preservation of meaning across time, context loss, handoffs or representation changes; stronger than merely retaining the same records | Evolving practice |
| Scope drift | Unapproved expansion of work | Failure mode |
| Agent echo chamber | Apparent agreement caused by shared evidence or assumptions | Generalized lesson |
| White-couch failure | Attractive coherent interpretation built on missing evidence | Generalized lesson |

Names are not dependencies. Implementations may use different names. A surviving name or record does not prove that its meaning survived.
