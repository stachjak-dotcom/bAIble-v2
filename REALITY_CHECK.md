# bAIble v2 — Reality Check

Reality Check is a verification mechanism, not another personality or agent.

Compare human intent, current AI interpretation, verified facts/evidence, assumptions, hypotheses, uncertainties, conflicts, missing context and the next required check.

Human says X → AI interprets X' → check agreement/divergence/missing data/scope drift.

If the problem is “we did not check”, record the missing check instead of hiding it behind “uncertain”.
