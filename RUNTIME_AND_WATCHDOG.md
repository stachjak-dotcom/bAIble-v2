# bAIble v2 — Runtime & Watchdog

rAIda coordinates task state, context/preflight, role/scope, planning, approval gates, execution handoff, evidence, verification and authorized continuation.

Watchdog may inspect, classify continuity, dispatch an authorized next task and escalate human gates. It must not invent work, reinterpret intent, manufacture evidence, override gates or mutate epistemic truth merely to continue.

A runtime test proves only the behavior exercised. A live E2E claim requires evidence from the real boundary.
